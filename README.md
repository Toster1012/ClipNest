# ClipNest

Буфер обмена для Windows. Сохраняет скопированный текст, картинки, файлы и папки. Открывается по Win+V, работает в трее.

## Использование

- Win+V открывает историю. Повторное нажатие, Esc или клик в другое окно скрывают её.
- Поиск фильтрует записи по тексту, имени и пути файла.
- В окне Win+V обычный клик вставляет запись в прежнее поле ввода и закрывает панель.
- Протягивание зажатой мышью выделяет несколько записей без вставки. После этого клик по любой выделенной карточке вставляет весь набор. Также работают Ctrl/Shift и Ctrl+A.
- Несколько записей вставляются последовательно, сверху вниз по списку. Между вставками есть пауза для обработки данных приложением. При смене активного окна или поля последовательность останавливается.
- Чтобы перетащить выбранное в другое приложение, потяните ручку справа от записи.
- Кнопка копирования и Ctrl+C помещают выбранное в буфер. Enter в панели Win+V вставляет выбранное, а в большом окне копирует. В большом окне обычный клик только выделяет карточки.
- Delete удаляет выбранные записи из истории. Исходные файлы не удаляются.
- «Очистить» очищает историю и текущий буфер Windows.
- Большое окно и настройки открываются через правый клик по значку в трее.

Лимит по умолчанию: 100 записей. При заполнении удаляются самые старые. В настройках можно изменить лимит и включить автозапуск.

Галочка «Открывать буфер в правом нижнем углу» включена по умолчанию. Если её снять и сохранить настройки, панель будет открываться рядом с курсором. В обоих режимах окно ограничено рабочей областью монитора с курсором, с учётом панели задач и масштаба экрана. Если места недостаточно, окно уменьшается до доступного размера.

## Хранение

История очищается при выходе. Закрытие окна оставляет программу в трее. Для полного выхода используйте пункт меню «Выйти и очистить историю».

Для обычных файлов и папок хранятся пути к оригиналам. Если оригинал удалить или переместить, запись больше нельзя будет передать. Изображения из буфера и снимки файлов изображений до 256 МиБ хранятся во временной папке `%LOCALAPPDATA%\ClipNest\Sessions`.

Настройки находятся в `%LOCALAPPDATA%\ClipNest\settings.json`.

Win+V перехватывается только пока работает ClipNest. После выхода это сочетание снова обрабатывает Windows. Программа не меняет системные настройки истории буфера.

Вставка использует Ctrl+V: приложение должно поддерживать вставку выбранного типа данных. ClipNest не отправляет сообщения по Enter. В некоторых чатах загрузка вложения открывает отдельное окно или меняет фокус; тогда последовательность остановится. Очень медленное приложение может не успеть обработать несколько вставок. Для вставки в приложение, запущенное от администратора, ClipNest также нужны права администратора.

## Обновления

Текущая версия — 1.1.0. ClipNest проверяет последний стабильный релиз [на GitHub](https://github.com/Toster1012/ClipNest/releases) при запуске и раз в сутки. Проверка не требует входа в GitHub. Если сеть недоступна, программа продолжает работать; проверку можно повторить через пункт «Проверить обновления» в трее.

Окно предлагает «Обновить» и «Позже». «Позже» скрывает предложение до следующего запуска программы. При следующем входе в Windows оно появится снова, если ClipNest включён в автозапуск и обновление ещё доступно. Во время работы с панелью вставки предложение откладывается, чтобы не перехватывать ввод.

После согласия архив скачивается и проверяется по SHA-256 из GitHub. Программа закрывается, установщик заменяет файлы и запускает ClipNest в трее. Настройки и автозапуск сохраняются; текущая история, как и при обычном выходе, очищается. При ошибке замены установщик восстанавливает прежние файлы. Для обновления нужна возможность записи в папку программы; например, папка пользователя подходит без прав администратора.

Версия 1.0 не содержит механизма обновления: переход с неё на 1.1.0 нужно выполнить вручную один раз.

Для публикации обновления создайте стабильный релиз с тегом `release-1.2.0`, `v1.2.0` или `1.2.0` и прикрепите собранный `win-x64.zip`. Версия в `ClipNest.csproj` должна совпадать с тегом. Поддерживается также имя `ClipNest-1.2.0-win-x64.zip`. Черновики и предварительные версии не устанавливаются. ZIP исходного кода GitHub не подходит.

## Windows 10

Сборка предназначена для Windows 10 x64 (1809 и новее) и Windows 11 x64. Среда .NET входит в portable-архив. Оформление, доступное только в Windows 11, на Windows 10 пропускается. Совместимость API и сборки проверена; запуск именно на Windows 10 требует отдельного прогона на таком ПК или виртуальной машине.

## Сборка

Нужны Windows 10/11 x64 и .NET 10 SDK.

```powershell
.\build.ps1
```

Исходники находятся в `src/ClipNest`.

Готовые файлы: `artifacts/Release/1.1.0/win-x64/ClipNest.exe`. Архив для GitHub Release: `artifacts/Release/1.1.0/win-x64.zip`.
