# ClipNest

Буфер обмена для Windows. Сохраняет скопированный текст, картинки, файлы и папки. Открывается по Win+V, работает в трее.

## Запуск

Откройте `artifacts/Release/win-x64/ClipNest.exe`. В этой сборке уже есть .NET, устанавливать его отдельно не нужно. Все файлы рядом с exe должны оставаться в одной папке.

Если запущена предыдущая версия, сначала завершите её через меню в трее.

## Использование

- Win+V открывает историю. Повторное нажатие, Esc или клик в другое окно скрывают её.
- Поиск фильтрует записи по тексту, имени и пути файла.
- Клик отмечает запись. Протягивание мышью выделяет несколько. Также работают Ctrl+A и Shift.
- Чтобы перетащить выбранное в другое приложение, потяните ручку справа от записи.
- Кнопка копирования, Ctrl+C или Enter помещает выбранное в буфер. Для вставки используйте Ctrl+V.
- Delete удаляет выбранные записи из истории. Исходные файлы не удаляются.
- «Очистить» очищает историю и текущий буфер Windows.
- Большое окно и настройки открываются через правый клик по значку в трее.

Лимит по умолчанию: 100 записей. При заполнении удаляются самые старые. В настройках можно изменить лимит и включить автозапуск.

## Хранение

История очищается при выходе. Закрытие окна оставляет программу в трее. Для полного выхода используйте пункт меню «Выйти и очистить историю».

Для обычных файлов и папок хранятся пути к оригиналам. Если оригинал удалить или переместить, запись больше нельзя будет передать. Изображения из буфера и снимки файлов изображений до 256 МиБ хранятся во временной папке `%LOCALAPPDATA%\ClipNest\Sessions`.

Настройки находятся в `%LOCALAPPDATA%\ClipNest\settings.json`.

Win+V перехватывается только пока работает ClipNest. После выхода это сочетание снова обрабатывает Windows. Программа не меняет системные настройки истории буфера.

## Сборка

Нужны Windows 10/11 x64 и .NET 10 SDK.

```powershell
.\build.ps1
```

Скрипт собирает Release и автономную версию в `artifacts/Release/win-x64`. Архив не создаётся. Папки `artifacts`, `bin` и `obj` исключены из Git.

Исходники находятся в `src/ClipNest`, решение: `ClipNest.slnx`.
